# Changelog

## v0.1.0 - experimental research
- Dependency-free PE32+ AMD64 parser.
- Deterministic no-import PE test executable with a DIR64 relocation.
- Strictly allowlisted host-side native mapping and Win64 ABI call.
- Unsigned Intel macOS standalone demo .app prototype.
- Linux/macOS CI and basic integration tests.
- No general Windows application compatibility.
